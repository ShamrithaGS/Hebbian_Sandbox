2. Memory Formation

WHAT YOU SEE
The 200x200 matrix representing all 40,000 synaptic connections. It lights up as connections change.

WHY IT HAPPENS
The Hebbian update rule strengthens connections between neurons that fire at the same time. The memory is now physically stored in the synapse weights.

Teach the network this pattern. Watch the synapses.

3. Recall Signal Flow

WHAT YOU SEE
We hide the original pattern and provide a partial clue. The cue sends signals through the newly strengthened synapses, calculating activation scores (shown as a glowing heat map) to reconstruct the full memory.

WHY IT HAPPENS
Because the original neurons were wired together, stimulating just a few of them triggers a cascade that activates the rest.

Give it a clue. Can it reconstruct the rest?

4. Truth vs Recall

WHAT YOU SEE
A Diff View. Solid amber means a correct recall. A dashed outline means the network forgot that neuron. Red means the network hallucinated a false memory.

WHY IT HAPPENS
The network selects the most strongly activated neurons. With a fresh memory and no noise, it reconstructs perfectly.

Proceed to the first challenge.

5. Predict Interference

WHAT YOU SEE
The synaptic matrix gets chaotic and messy as false connections strengthen.

WHY IT HAPPENS
When the network learns new distractor patterns, they share the exact same synapses. This crosstalk overwrites the original memory, causing hallucinations.

CHALLENGE 1

14. Dense Global vs Local Sparse

In the Transformer, every token attends to every other token — a global, dense operation. BDH instead uses locally interacting neuron particles [BDH Paper]: each neuron only exchanges signals with its neighbors in the graph.

Dense / Global (Transformer)

Every node connects to every other node.

Local / Sparse (BDH)

Nodes interact only with local neighbors.

Conceptual simplification — not a literal depiction of a production BDH graph.

16. The Honest Limits

Our toy model isolates one conceptual mechanism — synaptic-weight-based memory. But our toy is NOT BDH. Here is what is missing:

Scale-free graph structure
TOY: Uses a dense 200×200 matrix.
BDH: Uses a sparse graph with heavy-tailed degree distribution (hubs). [BDH Paper]
Spiking neuron dynamics
TOY: Uses simple binary activations.
BDH: Models spiking neurons. [BDH Paper]
Sequence processing
TOY: Encodes one static pattern array.
BDH: Processes sequential token inputs continuously over time. [BDH Paper]
Attention derivation
TOY: Recall is a simple dot-product threshold.
BDH: Formally derives its mechanism from linear algebra and Transformer attention equations. (Kosowski et al. 2025, §2.3)
Trained architecture
TOY: A fixed, algorithmic pedagogical model.
BDH: A trained, GPU-optimized Large Language Model (10M - 1B parameters). [BDH Paper]
BDH-CQ Architecture
BDH-CQ is not directly used here because its focus is test-time task adaptation from demonstrations, whereas this experience isolates within-session synaptic memory, interference, and decay.

17. Why This Matters

The Dragon Hatchling is consistent with the intuition behind real architectural choices in a modern language model — sharing the concepts you explored like synaptic memory delays, interference, and recall.

BDH shows that individual synapses can be monosemantic (linked to specific concepts), giving researchers a window into the model's internal reasoning. This interpretability is an inherent feature of the architecture, not an add-on. [BDH Paper]
